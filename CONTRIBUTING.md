# Contributing to Smart Form Guard

First off, thanks for taking the time to contribute! 🎉

## How to Contribute

1.  **Fork the repo** and create your branch from `main`.
2.  **Add tests** for your new validator or feature.
3.  **Ensure tests pass**: Run `flutter test`.
4.  **Format your code**: Run `dart format .`.
5.  **Submit a Pull Request**!

## Please Keep in Mind
- Keep `SmartFormGuard` logic decoupled from Flutter UI as much as possible.
- Avoid breaking changes if possible.
